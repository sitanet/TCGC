WHAT IS IT?
═══════════
Bottom sheet modal that appears after user enters amount and clicks "Pay"
but BEFORE entering PIN. This is where user reviews all transaction details.


WHEN DOES IT APPEAR?
════════════════════
1. User enters amount on wallet screen
2. User clicks "Pay" button
3. THIS SHEET OPENS ← User reviews details here
4. User clicks "Pay" again
5. PIN entry sheet opens


WHAT'S DISPLAYED?
═════════════════

1. AMOUNT (Large & Bold)
   Display: ₦10,000.00
   Purpose: Shows base amount user entered
   Font: 36px, weight 800

2. TYPE BADGE (Gold Pill)
   Display: "TITHE", "GIVING", etc.
   Purpose: Shows transaction type
   Color: Gold (15% opacity bg)

3. DETAILS CARD (With Dividers)
   ├─ To: CityGate Church (with church icon)
   ├─ Purpose: Transaction type (Tithe, Giving, etc.)
   ├─ Account No.: 1234567890 (⚠️ if available)
   ├─ Account Name: Church Account (⚠️ if available)
   ├─ Amount: ₦10,000.00
   ├─ Fee: ₦50.00
   ├─ VAT: ₦10.00 (if > 0)
   └─ Total: ₦10,060.00 (BOLD, GOLD)

4. WALLET BALANCE CARD (Green Border)
   Display: ₦50,000 → ₦39,940 after ✓
   Purpose: Shows current balance and balance after transaction
   Icon: Green checkmark (balance sufficient)

5. PAY BUTTON (Gold)
   Action: Closes this sheet, opens PIN entry sheet

6. CLOSE BUTTON (X)
   Action: Closes this sheet without processing


KEY INFORMATION
═══════════════

AMOUNT:     User entered amount
FEE:        System calculated (typically 0.5% of amount)
VAT:        Tax on fee (typically 20% of fee)
TOTAL:      Amount + Fee + VAT ← This is deducted from wallet
BALANCE:    Current wallet balance
AFTER:      Balance - Total (what user has left after transaction)


EXAMPLE TRANSACTION
═══════════════════

User enters:           ₦10,000.00
System adds:
  Fee (0.5%):         +₦50.00
  VAT (20% on fee):   +₦10.00
                      ─────────
TOTAL:                ₦10,060.00

User's wallet:        ₦50,000.00
After transaction:    ₦39,940.00 (₦50,000 - ₦10,060)


OPTIONAL FIELDS
═══════════════

Account No.    ← Only shown if churchAccountNumber exists
               ← ⚠️ Privacy concern: May need to be hidden

               ← Redundant with "To" field (church name already shown)
