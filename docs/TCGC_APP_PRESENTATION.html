1. Introduction & Onboarding

1.1 App Launch - Get Started Screen

When users first open the app, they are greeted with a Get Started screen featuring:

  • Church branding and logo
  • Welcome message
  • Two options: Sign In (existing members) and Sign Up (new members)

1.2 User Registration (Sign Up)

Required Information:

FieldDescription
First NameUser's first name
Last NameUser's last name
EmailValid email address (used for login)
PasswordSecure password
Confirm PasswordPassword verification

Registration Process:

  1. User fills in registration form
  2. System validates all fields
  3. Account is created
  4. Email Confirmation is sent automatically
  5. User receives success message
Email Confirmation: User receives email with confirmation link that expires in 24 hours. Clicking the link activates the account. Users can request "Resend Confirmation" if needed.

1.3 User Sign In

Login Options:

  • Email + Password authentication
  • Biometric Login (Face ID / Fingerprint) - after initial setup

Sign In Flow:

  1. Enter email address
  2. Enter password
  3. Tap "Sign In"
  4. JWT tokens issued (access + refresh)
  5. Redirected to main app

Forgot Password:

  1. Tap "Forgot Password"
  2. Enter registered email
  3. Receive password reset link
  4. Set new password via secure web form
  5. Login with new credentials

1.4 Interests Selection (First-Time Setup)

After first login, users select their interests from available message categories for personalized content recommendations:

  • Sunday Service Messages
  • Bible Study
  • Prayer & Worship
  • Family & Marriage
  • Youth & Young Adults
  • Leadership
  • Special Programs

7. Wallet & Giving

7.1 Wallet Overview

Wallet Dashboard displays:

  • Current Balance (₦ Naira)
  • Account Number (9PSB Bank)
  • Account Name
  • Wallet Tier (0-3)
  • Quick action buttons

7.2 Wallet Setup (First Time)

StepActionDetails
1Create WalletAutomatic 9PSB account creation, real bank account number generated
2Set Transaction PINCreate 4-digit PIN, confirm PIN, used for all transactions
3NIN Verification (Optional)Enter NIN, verify phone, auto-fetch details, upgrade to Tier 1

7.3 Wallet Tiers

TierStatusDaily LimitSingle LimitBalance Limit
0Unverified₦0₦0₦0
1Basic₦50,000₦50,000₦300,000
2Standard₦500,000₦200,000₦500,000
3Premium₦5,000,000₦5,000,000Unlimited
Upgrade Requirements:
• Tier 1: NIN verification
• Tier 2: BVN verification + ID document
• Tier 3: Full KYC with address proof

7.4 Fund Wallet

Funding Method: Bank Transfer to generated account number

  1. View account number and bank name (9PSB)
  2. Copy account details
  3. Transfer from any bank
  4. Auto-credit via webhook

7.5 Giving/Offering

Give Page Process:

StepAction
1Select Giving Type: Tithe, Offering, Thanksgiving, Seeds, Building Fund, Missions
2Enter Amount: Minimum ₦100, shows wallet balance
3Confirm & Pay: Review details, enter PIN, confirm, receive success confirmation

7.6 Send Money (Transfer)

Person-to-Person Transfer:

  1. Enter recipient email
  2. Enter amount
  3. Enter transaction PIN
  4. Confirm transfer

Instant transfer between TCGC wallets with transaction recorded for both parties.

7.7 Transaction History

Transactions Page shows all wallet transactions with:

  • 🟢 Money In and 🔴 Money Out indicators
  • Amount, Date/Time, Status, Reference number
  • Filter options: Date range, Transaction type, Category
