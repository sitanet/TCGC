═══════════════════════════════════════════════════════════════════════════════
                           WHAT'S DISPLAYED
═══════════════════════════════════════════════════════════════════════════════

✅ ALWAYS SHOWN:
   ├─ Animated green checkmark icon with pulse effect
   ├─ "Payment Successful!" headline
   ├─ Confirmation message: "Your [type] has been received"
   ├─ Amount: Formatted with ₦ symbol, bold, large, gold color
   ├─ Type: Transaction type (Giving/Tithe/Send Money/etc)
   ├─ To: Recipient name ("The CityGate Church")
   ├─ Date: Full date and time (formatted)
   ├─ Inspirational quote with Bible verse
   ├─ Generate Receipt button (PNG/PDF options)
   └─ Back to Wallet button

✅ CONDITIONALLY SHOWN:
   └─ Reference number (only if transaction has reference)

❌ NEVER SHOWN:
   ├─ Account numbers (REMOVED - Privacy/Security)
   ├─ Donor/Sender name (even if available)
   ├─ Account names
   ├─ Bank details
   └─ Internal transaction IDs


═══════════════════════════════════════════════════════════════════════════════
                         FIELD BREAKDOWN
═══════════════════════════════════════════════════════════════════════════════

┌─ AMOUNT
│  ├─ Format: "₦10,000.00" or "₦50,000"
│  ├─ Style: Bold, 1.1x normal font size, GOLD color
│  ├─ Importance: High - User confirms they sent this amount
│  └─ Example: ₦10,000.00

├─ TYPE
│  ├─ Values: "Giving", "Tithe", "Send Money", etc.
│  ├─ Style: Normal weight, standard color
│  ├─ Purpose: Clarifies transaction category
│  └─ Example: "Giving"

├─ TO (RECIPIENT)
│  ├─ Current value: "The CityGate Church" (hardcoded)
│  ├─ Style: Normal weight, standard color
│  ├─ Purpose: Shows who received the money
│  └─ Note: Could be dynamic in future versions

├─ DATE & TIME
│  ├─ Format: "10 Jan, 2025 at 2:30 PM"
│  ├─ Style: Normal weight, secondary/gray color
│  ├─ Purpose: Transaction timestamp
│  └─ Timezone: Device local time

├─ REFERENCE (OPTIONAL)
│  ├─ Format: Unique transaction ID
│  ├─ Style: Normal weight, monospace recommended
│  ├─ Purpose: Support/tracking reference
│  ├─ Example: "TXN1704928200123"
│  └─ Shown: Only if widget.reference is not null

└─ INSPIRATIONAL MESSAGE
   ├─ Content: Bible verse or inspirational quote
   ├─ Color: Gold with transparent background
   ├─ Font: Italic, smaller size
   └─ Example: "Give, and it will be given to you..." - Luke 6:38


═══════════════════════════════════════════════════════════════════════════════
                         VISUAL DETAILS
═══════════════════════════════════════════════════════════════════════════════

ICON ANIMATION:
  Stage 1 (0-100ms): Waiting for build
  Stage 2 (100-200ms): Icon starts scaling (elastic easing)
  Stage 3 (200-800ms): Checkmark animates in with rotation
  Stage 4 (0-2500ms): Confetti falls from top
  Continuous: Pulse glow expands/contracts (1500ms cycle)

TEXT ANIMATIONS:
  Timeline: 300-1100ms
  Effect: Slide up + fade in
  Easing: Ease-out curve
  Result: Smooth entrance after icon appears

LAYOUT:
  Max width: Responsive (mobile/tablet/desktop)
  Padding: Horizontal padding based on device
  Colors: Adapt to dark/light theme
  Shadows: Subtle shadows on cards and buttons

COLORS (Light Mode):
  Background: White
  Card: Light gray (#f3f3f3)
  Text: Dark gray/black
  Accent: Gold (primary brand color)
  Icon: Green checkmark (success green)
  Quote: Gold on semi-transparent gold

COLORS (Dark Mode):
  Background: Dark gray/black
  Card: Dark card color
  Text: White/light gray
  Accent: Gold (unchanged)
  Icon: Green checkmark (unchanged)
  Quote: Gold on semi-transparent gold

                      RECEIPT GENERATION
═══════════════════════════════════════════════════════════════════════════════

┌─ PNG/IMAGE FORMAT

│  ├─ Best for: Social media sharing, WhatsApp, etc.
│  ├─ Includes: Amount, type, date, reference, quote
│  └─ Resolution: High-quality screenshot

└─ PDF FORMAT
   ├─ Professional document format
   ├─ Best for: Email, printing, archiving
   ├─ Includes: Same details as PNG + formatted professionally
   └─ Features: Embeds all transaction info, logo, quote

═══════════════════════════════════════════════════════════════════════════════
                         NAVIGATION
═══════════════════════════════════════════════════════════════════════════════

BUTTONS:

1. Generate Receipt
   ├─ Taps show modal with PNG/PDF options
   ├─ PNG selected: Generates image, shows share dialog
   ├─ PDF selected: Generates PDF, shows share dialog
   └─ Loading state: Spinner shows while generating

2. Back to Wallet
   ├─ Returns to main wallet page
   ├─ Sets active tab to wallet (index 3)
   ├─ Clears navigation stack
   └─ Resets all transaction pages

3. System Back Button
   ├─ Cannot go back (PopScope prevents it)
   ├─ Must use "Back to Wallet" button
   ├─ Ensures user doesn't accidentally leave without review
   └─ Design pattern: Prevent accidental back navigation
